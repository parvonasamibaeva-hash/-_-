Задача 2. Ладья

Даны две различные клетки шахматной доски. Определи, может ли ладья попасть с первой клетки на вторую одним ходом.

Условие

Программа получает четыре числа от 1 до 8: номер столбца и номер строки первой клетки, затем номер столбца и номер строки второй клетки.

Выведи YES, если ладья может сделать такой ход, и NO в противном случае.

Если забыл теорию

Ладья ходит только по прямой:
• по вертикали — столбец не меняется;
• по горизонтали — строка не меняется.

Поэтому нужно проверить два условия:
x1 == x2
или
y1 == y2

Если подходит хотя бы одно из условий, используется or.

Твоя программа

Неудачных проверок: 0 / 5
Подсказка:
Подумай, при каком условии ладья остаётся в том же столбце, а при каком — в той же строке. Если подходит хотя бы одно из условий, какое логическое слово нужно использовать?
