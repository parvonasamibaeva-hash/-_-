Условие

Если забыл теорию

Быстрый маршрут решения:

1. Что вводит пользователь?
2. Что нужно проверить?
3. Как записать условие?
4. Что сделать, если условие выполнилось?
5. Что делать иначе?

Не знаешь, что написать — сначала сформулируй условие словами.

Твоя программа

Неудачных проверок: 0 / 5
Программа проверяется на скрытых тестах. Входные данные проверок не показываются ученику.

Теория — условные операторы

1. if — если

Используем, когда нужно проверить условие. 

if условие:
    действие

Например: 

age = 15

if age >= 12:
    print("Можно")

2. else — иначе

Используем, если условие не выполнилось. 

if условие:
    действие 1
else:
    действие 2

3. elif — иначе, если

Используем, когда вариантов больше двух. 

if условие 1:
    действие 1
elif условие 2:
    действие 2
else:
    действие 3

4. Операторы сравнения

> больше · < меньше · == равно · >= больше или равно · <= меньше или равно · != не равно

5. and — И

Должны выполняться оба условия. 

age >= 12 and height >= 140

6. or — ИЛИ

Должно выполниться хотя бы одно условие. 

age < 12 or height < 140

7. Строки

lower() переводит строку в нижний регистр, upper() — в верхний. 

word = "PyThOn"
print(word.lower())

in проверяет, содержится ли значение внутри строки. 

"a" in "cat"

8. Индексы и len()

Индексация строки начинается с 0. 

word = "Python"

word[0]  # P
word[5]  # n
len(word)  # 6

9. random

import random

a = random.randint(1, 10)

Оба значения диапазона входят в него.
